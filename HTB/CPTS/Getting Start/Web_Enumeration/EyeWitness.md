# EyeWitness

## কী?

`EyeWitness` একটি web reconnaissance/supporting tool, যা এই section অনুযায়ী:

- Target web applications-এর screenshot নিতে পারে
- Web applications fingerprint করতে পারে
- Possible default credentials identify করতে সাহায্য করতে পারে

## এই Section-এ Role

Web enumeration-এর সময় অনেক web application পাওয়া গেলে visual inspection এবং fingerprinting-এর জন্য EyeWitness useful supporting tool হতে পারে।

```text
Multiple Web Targets
        ↓
    EyeWitness
        ↓
Screenshots / Fingerprinting / Possible default credentials
```

## Important

Provided section-এ EyeWitness-এর কোনো command syntax বা installation procedure দেওয়া হয়নি। তাই এই file-এ সেই source-এর বাইরে command যোগ করা হয়নি।
