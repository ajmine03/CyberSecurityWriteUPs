# ffuf

## কী?

`ffuf` একটি web fuzzing tool। এই section-এ এটিকে `GoBuster`-এর পাশাপাশি hidden files/directories discover করার একটি tool হিসেবে উল্লেখ করা হয়েছে।

Source-এ `ffuf`-এর কোনো specific command example দেওয়া হয়নি।

## এই Section-এ এর ভূমিকা

Web application discover করার পরে:

```text
Web Application
      ↓
Hidden files/directories খোঁজা
      ↓
ffuf / GoBuster
```

এর মাধ্যমে এমন resource-এর clue পাওয়া যেতে পারে যেগুলো public navigation-এ দেখা যায় না।

## Important

এই section-এর source `ffuf`-এর usage syntax বা options explain করে না। তাই এখানে source-এর বাইরে কোনো commandকে section-এর content হিসেবে ধরা হয়নি।

আরও detailed `ffuf` usage-এর জন্য source নিজেই `Attacking Web Applications with Ffuf` module-এর দিকে নির্দেশ করেছে।
