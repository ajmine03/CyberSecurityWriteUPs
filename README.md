# Cyber Security Writeups

> **Live Knowledge Base & Documentation**: [https://ajmine03.github.io/CyberSecurityWriteUPs/](https://ajmine03.github.io/CyberSecurityWriteUPs/)

A curated repository of Capture The Flag solutions, Hack The Box CPTS methodology notes, TryHackMe lab walkthroughs, and offensive security tooling references.

---

## Sections

- **[CTF Writeups](https://ajmine03.github.io/CyberSecurityWriteUPs/CTF/)**: picoCTF and competitive event challenges covering General Skills, Binary Exploitation, and Reverse Engineering.
- **[Hack The Box](https://ajmine03.github.io/CyberSecurityWriteUPs/HTB/)**: Certified Penetration Testing Specialist (CPTS) notes, service enumeration, and web reconnaissance playbooks.
- **[TryHackMe](https://ajmine03.github.io/CyberSecurityWriteUPs/TryHackMe/)**: Room walkthroughs, CVE deep-dives (e.g. CVE-2024-21413), Metasploit, SQLMap, and tooling guides.
- **[Commands & Cheatsheets](https://ajmine03.github.io/CyberSecurityWriteUPs/Commands/)**: Fast references for Linux permissions (`chmod`), downloaders (`aria2c`), and Python environments.

---

## Disclaimer

This repository is maintained for educational and authorized penetration testing purposes only. Methodologies and tooling references should only be utilized in lab environments or on systems where explicit authorization has been granted.
